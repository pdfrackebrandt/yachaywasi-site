# Yachaywasi website

The public page for Yachaywasi, served at https://yachaywasi.rackebrandt.pe from the public
repository `pdfrackebrandt/yachaywasi-site` (GitHub Pages, `main` branch root). This folder is its
source: copy it over that repository's files to publish a change. It holds only HTML, CSS, the icons
and two OFL fonts (Instrument Serif and Inter, the ones rackebrandt.pe ships); no research code, data
or credentials, and no scripts.

The icon is Rikuy's family mark (dark tile, italic letter, a caret in the tool's colour), drawn with
the recipe of rikuy's `build/icons/make.py`; Yachaywasi's caret runs lavender to violet.

Copy rules (docs/OWNER_DECISIONS.md): AI scores are opinion, accuracy is claimed only for the code
rerun and the maths checks, and the NBER grading numbers stay off the page until their paper is out
(owner, 20 Nov 2026).
